# Repository instructions

## Release policy

- Keep the value in `VERSION` unchanged between releases.
- Do not change the project version, create a tag, or publish a release unless the user explicitly asks for a new release.
- When a new release is requested, update `VERSION` as part of release preparation and use that exact value for the Git tag and GitHub release.
- Keep published release notes on the GitHub Releases page instead of adding a release-notes file to the repository.
